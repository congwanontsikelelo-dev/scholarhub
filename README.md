# ScholarHub

A student financial assistance platform that allows students to browse scholarships, apply, manage payment plans, and view work-study opportunities.

## Tech Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express
- Demo database: local JSON-backed store for interview/demo usage

## Features
- Student registration and login
- Scholarship listings and details
- Scholarship application workflow
- Work-study program browsing and application
- Notifications and dashboard views
- Payment plan management
- Admin dashboard for reviewing applications

## Run locally

### Backend
```bash
cd server
node seed.js
node server.js
```

### Frontend
```bash
cd client
npm run dev -- --host 127.0.0.1
```

Open:
- Frontend: http://127.0.0.1:5173
- API: http://127.0.0.1:5000
